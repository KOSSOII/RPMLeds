The mod allows full customization of RPM LED behavior on the wheel. You can configure when the LEDs start lighting up and when they reach the maximum point using two sliders expressed in percentages (1–100%):
Start Point – RPM percentage at which the LEDs begin to activate
Max Point (Shift Point) – RPM percentage at which all LEDs are fully lit
The maximum RPM value is automatically detected from the vehicle’s rev limiter or race tachometer if available. If neither source is installed or detected, the mod defaults the maximum RPM to 7,000 RPM.
Additionally, a manual mode is available, allowing you to set a custom maximum RPM value of up to 10,000 RPM
